Description

The original Snake game dates back to 1976. Interestingly, the earliest version was for two players. Its simple and addictive concept popularised the game and the most famous variant appeared on Nokia mobile phones in 1998. Most people recognise that version. On a small static, usually square screen, the player controls a snake that collects food which appears randomly on the map. Eating food grows the snake and occupies more of the map. Each food gives one point; the snake grows and the game becomes harder because the player must avoid colliding with the snake's tail or the walls while space decreases. This requires practice and some strategy. A human player learns these simple rules quickly and can reach decent scores. But what if we wanted to teach just a few neurons? Can a small neural network learn to collect points in this classic game, or is a human necessary? That is the question investigated here.

Problem definition

To teach a small neural network to play Snake, we can use many approaches such as reinforcement learning or an evolutionary algorithm. I chose an evolutionary algorithm because the goal of this project is to simulate evolution, and an evolutionary approach fits well. The evolutionary algorithm needs careful configuration: it contains many parameters that influence the direction and speed of evolution.

Goal

The project has two goals: one official and one unofficial.

  • The official goal is to find suitable settings for the evolutionary algorithm parameters to speed up learning of the neural network.
  • The unofficial/personal goal is to train an agent that reliably scores at least 10 points and whose behavior is not just random collecting.

Method

As mentioned, this work uses an evolutionary algorithm to simulate evolution of a neural network. The implementation uses Python. For matrix operations we use NumPy; for plotting results we use Matplotlib; and for rendering the game (not essential but handy) we use Tkinter.

Model

Agents

Each agent is a neural network. The agent "sees" in eight directions (up, down, left, right, up-right, down-right, down-left, up-left) from the snake's head. For each direction it senses the distance to the wall, the distance to the apple (if visible in that direction), and the distance to its own tail (if visible). Thus the input layer has 24 neurons (8 directions x 3 indicators) plus 4 neurons indicating the current heading of the snake's head — 28 neurons in total. The number of hidden layers and neurons is fixed for simplicity: two hidden layers with 20 and 12 neurons. Weight matrices are initialized uniformly at random and later changed by mutations. The output layer has 4 neurons corresponding to Up, Down, Left, Right — the chosen output is the neuron with the largest value.

Activations

Hidden-layer neurons use ReLU as the activation function:

$$\mathrm{ReLU}(x)=\max(0, x)$$

The output-layer neurons use the Sigmoid activation; the final action is the neuron with the highest output value:

$$\sigma(x)=\frac{1}{1+e^{-x}}$$

Environment

The environment is the standard Snake game used in the evolutionary simulation. The board is 10x10 (height x width) and food is placed at random positions. To simulate evolution we run multiple generations E and in each generation a population of N agents. Each agent plays g independent games (g > 1) because agents can be unlucky or lucky; we average results of g games per agent.

After games are played, a fitness score for the best agent is computed. Fitness is a function of points collected and steps taken. The fitness function used (inspired by SnakeFusion) rewards surviving longer initially and later rewards point collection. For small point counts (<10) fitness grows quickly with points; for larger point counts (≥10) exponential growth stabilises and further increase is roughly linear, preventing runaway fitness values for very high scores.

Individuals for the next generation are selected based on fitness and the elitism rate e: the top N * e individuals are copied directly. The rest of the new generation is filled with offspring created by crossing two randomly selected parents (roulette selection). Crossover is performed by iterating through weights and randomly choosing the weight from one parent. Offspring weights are then mutated with probability m per weight (additive normal noise).

Fixed variables

  • Number of generations G = 500
  • Population size N = 500
  • Games per individual g = 3
  • Hidden layers = 2
  • Neurons in first hidden layer = 20
  • Neurons in second hidden layer = 12
  • Hidden-layer activation = ReLU
  • Output-layer activation = Sigmoid
  • Board size = 10x10 cells

Free variables

Elitism rate e and mutation rate m.

IT'S ALIVE

After thousands of failed agents and hundreds of generations, agents finally started to seek food consistently. First 6, then 8, then 10 pieces. Around generation ~400 a successful agent could reach good scores but avoided the top-left corner for some reason. After ~800 generations (about 2 million games) the best result was a score of 42!!!

I couldn't reproduce that exact score later. I only implemented a fixed random seed after that run, so I don't know the exact randomness used. Subsequent runs reliably reached scores around 30. I saved network weights (the agents' "brains") and can replay them:

Each replay scores above 10 points, so the unofficial goal is met. I also added a head to make the UI clearer.

Conclusion

From the observed results we infer that the evolutionary algorithm performs best for training neural networks to play Snake with elitism = 0.002 and mutation = 0.05.

Interestingly, elitism = 0.002 in a population of 500 means a single agent is selected (N*e = 1), so only the top individual moves to the next generation. Another observation: most evolutions showed the largest point increases around generation ~200+. High mutation rates sped up learning but results were less stable. From standard deviation and average scores, mutation = 0.05 produced fast but sustainable improvements.
